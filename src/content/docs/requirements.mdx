<Aside type="caution">
  All four requirement categories below must be satisfied before requesting an audit. Review each section carefully and confirm readiness with your Microsoft Partner Development Manager (PDM).
</Aside>

## Requirement 1 – Active Solutions Partner Designation

Your organisation must hold an active Solutions Partner designation in at least one of the following:

| Designation | How to verify |
| --- | --- |
| Solutions Partner for Data and AI (Azure) | Partner Center -> Overview -> Membership |
| Solutions Partner for Digital and App Innovation (Azure) | Partner Center -> Overview -> Membership |

<Aside type="note">
  **Evidence needed:** Screenshot of active designation from Partner Center, or the Partner Center PDF report showing designation status.
</Aside>

## Requirement 2 – Azure Consumed Revenue Performance

Your organisation must demonstrate 15,000 USD of Azure Consumed Revenue in the last three months across each of the following pillars independently.

### Pillar 1 – AI Services

- Rest of Azure AI
- Azure OpenAI
- 3P GPU

### Pillar 2 – Application Platform

| Service Category | Included Services |
| --- | --- |
| App platform services | App Service, Logic Apps, API Management, Functions |
| Container services | Azure Kubernetes Service, Azure Container Apps, Azure Red Hat OpenShift |
| Developer services and platform | GitHub products and GitHub Copilot |

### Pillar 3 – Data Platform

| Strategic pillar | Included services |
| --- | --- |
| Modern DB | Cosmos DB, SQL DB Hyperscale |
| MySQL and PostgreSQL PaaS | Azure Database for MySQL, Azure Database for PostgreSQL |
| Azure SQL Core | Azure SQL Database |
| Fabric F SKU | Microsoft Fabric F SKU |

<Aside type="note">
  **Evidence needed:** Partner Center exports annotated to show pillar totals and the unique customer count.
</Aside>

## Requirement 3 – Certifications

Your organisation must have at least five individuals pass the required certifications, with each certification held by at least one individual.

| Certification | Minimum holders | Exam code |
| --- | --- | --- |
| Azure Developer Associate | 1 | AZ-204 |
| DevOps Engineer Expert | 1 | AZ-400 |
| Azure AI Engineer Associate | 1 | AI-102 |
| Azure Cosmos DB Developer Specialty | 1 | DP-420 |

<Aside type="note">
  **Evidence needed:** Microsoft Learn transcripts or verification links for each individual, plus a mapping table showing name, certification, and expiry date.
</Aside>

## Requirement 4 – Third-Party Remote Audit

<Steps>
1. Confirm pre-qualification across the first three requirements.
2. Request the audit through Partner Center.
3. Receive the assigned auditor and complete the kickoff call.
4. Submit the evidence package.
5. Complete the review or interview.
6. Address remediation findings if required.
7. Receive the audit pass confirmation.
</Steps>

<Aside type="note">
  **Evidence needed:** This repository is the preparation pack. Use the Module A and Module B pages to collect control-level evidence.
</Aside>

## Phase 0: Pre-Engagement (Week -2 to 0)

| Area | Detail |
| --- | --- |
| Activities | Qualification, Partner Development Manager alignment, Azure Consumed Revenue check, subscription setup, stakeholder mapping |
| Deliverables | Qualification questionnaire, kickoff agenda, subscription access checklist |
| Gate | Signed statement of work |

## Phase 1: Discovery (Week 1-2)

| Area | Detail |
| --- | --- |
| Activities | Discovery workshop day 1 for business outcomes, day 2 for architecture, threat model, data classification |
| Deliverables | Discovery report, stakeholder map, initial risk register |
| Gate | Customer sign-off on discovery report |
| Assessments | Run Azure Architecture Review baseline |

## Phase 2: Design (Week 3-4)

| Area | Detail |
| --- | --- |
| Activities | Reference architecture selection, Solution Architecture Design, Well-Architected Framework assessment, security review |
| Deliverables | Solution Architecture Design, architecture decision records, Well-Architected Framework findings report |
| Gate | Customer sign-off on Solution Architecture Design |
| Assessments | Run the Well-Architected Framework AI workload assessment |

## Phase 3: Build (Week 5-10)

| Area | Detail |
| --- | --- |
| Activities | Sprint-based delivery, daily standups, bi-weekly demos, CI/CD setup |
| Sprint structure | Sprint 0 for infrastructure, Sprint 1-N for features, final sprint for hardening |
| Deliverables | Working software, sprint reports, test results |
| Gate | Definition of done met and security test complete |

## Phase 4: Go-Live (Week 11-12)

| Area | Detail |
| --- | --- |
| Activities | User acceptance testing, go-live checklist, runbook walkthrough, go-live day execution |
| Deliverables | Detailed Technical Design signed, UAT sign-off, runbook, go-live checklist |
| Gate | Customer sponsors sign go-live acceptance |

## Phase 5: Knowledge Transfer (Week 11-13)

| Area | Detail |
| --- | --- |
| Activities | Training sessions by role, hands-on labs, exit assessments |
| Deliverables | Training materials, recordings, exit assessment sign-offs |
| Gate | All receiving team members pass exit assessment |

## Phase 6: Hypercare (Week 13-16)

| Area | Detail |
| --- | --- |
| Activities | Daily standup, alert monitoring, weekly steering committee, incident handling |
| Deliverables | Weekly KPI reports, incident log, exit certificate |
| Gate | 14 consecutive days without Sev-1, all Service Level Objectives met, customer team handled an incident unaided |

## Phase 7: Closure (Week 16-17)

| Area | Detail |
| --- | --- |
| Activities | Retrospective, final invoice trigger, audit evidence package preparation, inner-source contribution |
| Deliverables | Closure report, support Service Level Agreement, audit evidence package |
| Gate | Signed closure report |

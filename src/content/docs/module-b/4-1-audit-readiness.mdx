## What the Auditor Checks

This control validates that your organisation approached the audit in a **structured, prepared manner** — not scrambled at the last minute. The auditor may ask about your internal preparation process and evidence organisation.

**Typical questions:**
- How was the evidence package prepared and organised?
- Who was responsible for each area of evidence?
- Was a pre-audit self-assessment conducted?

<Aside type="tip">
  This page doubles as your **internal pre-audit checklist** — work through it before submitting
  your evidence package to the auditor.
</Aside>

## Evidence Quality Standards

All submitted documents should meet these standards:

| Standard | Requirement |
|---|---|
| **Format** | PDF preferred; Excel/Word accepted for tracker documents |
| **File naming** | `[ControlRef]_[DocumentType]_[Version].pdf` |
| **Date visibility** | All documents must show a creation or review date |
| **Version control** | Documents should have a version number or date |
| **Completeness** | No broken links, missing pages, or placeholder text |
| **Anonymisation** | Customer names redacted where required |

## Submission Steps

<Steps>
1. Complete all evidence for each control using the Module A and B pages in this guide
2. Run the pre-audit self-assessment checklist (above)
3. Package evidence into the folder structure above
4. Create the Evidence Index spreadsheet
5. Conduct an internal review with your Delivery Lead and Technical Lead
6. Submit the package to the auditor via their specified channel (SharePoint link, email, or portal)
7. Confirm receipt with the auditor
</Steps>

## Common Gaps

| Gap | Remediation |
|---|---|
| Evidence submitted without an index | Create a simple Excel index before re-submission |
| Mixed file names with no control references | Rename all files to follow the `[ControlRef]_[Type]_[Version]` convention |
| Internal review not completed | Schedule a 2-hour evidence review session before submission |
| Submission channel not confirmed | Confirm with auditor at kickoff call; don't assume email is acceptable |

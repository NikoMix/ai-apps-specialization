## What the Auditor Checks

This control tests whether the partner prepared for the audit in a deliberate, governed way. The auditor wants to see ownership, a complete evidence pack, and internal quality control before anything is submitted.

A mature submission includes a self-assessment, a filing structure, evidence naming standards, and a named point of contact who can respond quickly when the auditor asks follow-up questions.

## Implementation Guidance

### Organise the pack

- Use one folder per control and keep file names aligned to control references.
- Create an evidence index that lists version, date, and a one-line explanation for every file.
- Store raw exports separately from annotated or redacted copies so nothing is lost if challenged.

### Run an internal audit

- Walk every control as if you were the auditor and ask whether the evidence is complete, current, and understandable without verbal explanation.
- Check that dates, document owners, and versions are visible on every core artefact.
- Assign a single owner for each follow-up response so the auditor receives fast, consistent answers.

### Prepare for questions

- Have the delivery lead and technical lead review the full pack before submission.
- Keep a gap log and remediation owner list in case the auditor requests clarifications.
- Treat the evidence package like a deliverable: version it, freeze it, and record what changed after each submission round.
